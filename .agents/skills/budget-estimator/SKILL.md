# Budget Estimator

Goal:
Assess affordability and budget pressure points.

Inputs:
- Destination
- Dates or season
- Duration
- Travelers count
- Travel style

Instructions:
1. Return category ranges for uncertainty.
2. Separate estimated from verified data.
3. Highlight top cost drivers.
4. Add practical optimization ideas.
5. Keep output decision-friendly.

Output format:
- feasibility
- estimated_total
- budget_breakdown
- pressure_points
- optimization_options
- confidence_notes
