# Entry Requirements Checker

Goal:
Provide an operational and cautious summary of travel-entry requirements.

Inputs:
- Traveler nationality
- Destination
- Date window
- Trip purpose

Instructions:
1. Never guess legal requirements.
2. Use trusted tools first.
3. Label each statement by confidence state.
4. Surface unknowns and manual checks clearly.
5. Keep wording risk-aware.

Output format:
- verification_status
- requirements_summary
- required_actions
- documents_to_prepare
- unknowns
